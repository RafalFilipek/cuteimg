# Changelog

## 0.3.0

- Zoom in and out with Ctrl+wheel, Ctrl+= and Ctrl+-, or the zoom control in the corner; Ctrl+0 fits the image to the window. Hold Space and drag to move around.
- A new capture shows up in the editor right away, without clicking the window first.
- Clicking the checkered area around the image drops the selection.
- The tool letters in the Shortcuts list show which tool they pick.

## 0.2.1

- Toolbar buttons show what they do and their shortcut when you hover or focus them.
- With the Pixelate tool active, clicking a pixelated area selects it again, so you can move, resize or delete it.

## 0.2.0

- Add text to screenshots with the new Text tool (T): bold text with an outline, or a label on a rounded color tag. Switch styles in the side panel, use Shift+Enter for a new line and double-click to edit.
- The toolbar fits narrow windows without hiding the window buttons.

## 0.1.0

The first release of cuteimg.

- Capture an area of the screen from anywhere with a global shortcut you choose and can test, or paste an image with Ctrl+V.
- Put screenshots on mesh and linear gradients, a rainbow, white or a custom color, with padding, rounded corners, a shadow and optional grain.
- Mark them up with arrows, rectangles and ellipses, and pixelate anything private.
- Copy the result or save it as a PNG.
- Light, dark and system themes.
- Updates itself from GitHub releases.
